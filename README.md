## 🇧🇷 Português

### 📚 Sobre o Repositório
Bem-vindo(a) ao meu repositório de soluções da plataforma **[Beecrowd](https://judge.beecrowd.com/pt/profile/1035557)** (antigo URI Online Judge).  
Este espaço foi criado com o objetivo de **praticar, aprimorar e documentar** minha evolução em lógica de programação, algoritmos e estruturas de dados por meio da resolução de desafios computacionais.

---

### 📌 O que é o Beecrowd?
O **Beecrowd** é uma das principais plataformas de treinamento para programadores, amplamente utilizada em universidades, maratonas de programação e preparação para entrevistas técnicas.  
A plataforma oferece problemas classificados por **nível de dificuldade e área do conhecimento**, permitindo um aprendizado progressivo e consistente.

---

### 🎯 Objetivos do Repositório
- ✔️ Desenvolver e fortalecer a lógica de programação  
- ✔️ Aplicar algoritmos clássicos e técnicas computacionais  
- ✔️ Praticar diferentes paradigmas de programação  
- ✔️ Consolidar conhecimentos em estruturas de dados  
- ✔️ Manter um histórico de aprendizado e evolução contínua  

---

### 📂 Organização dos Exercícios
Os exercícios seguem a mesma categorização utilizada pelo Beecrowd:

- 📁 **Iniciante**  
  Conceitos básicos de programação e lógica  

- 📁 **Estruturas e Bibliotecas**  
  Vetores, matrizes, listas, pilhas, filas e mapas  

- 📁 **Matemática**  
  Cálculos matemáticos, teoria dos números e problemas aritméticos  

- 📁 **Ad-Hoc**  
  Problemas variados que exigem criatividade e análise cuidadosa  

- 📁 **Strings**  
  Manipulação, análise e transformação de cadeias de caracteres  

- 📁 **Grafos e Geometria Computacional**  
  Caminhos mínimos, buscas, grafos e problemas geométricos  

- 📁 **Paradigmas**  
  Programação dinâmica, divisão e conquista, backtracking, entre outros

## 🇺🇸 English
📚 About This Repository
Welcome to my Beecrowd problem solutions repository.
This repository contains solutions to challenges from Beecrowd (formerly URI Online Judge), created to practice, improve, and document my progress in programming logic, algorithms, and data structures.

---

### 📌 What is Beecrowd?
Beecrowd is one of the most popular online judges for programmers, widely used in universities, competitive programming, and technical interview preparation.
It provides hundreds of problems categorized by difficulty level and subject, enabling structured and continuous learning.

---

### 🎯 Repository Goals
- ✔️ Improve problem-solving and programming logic
- ✔️ Apply classic algorithms and computational techniques
- ✔️ Practice different programming paradigms
- ✔️ Strengthen knowledge of data structures
- ✔️ Keep a clear record of learning progress and evolution

---

### 📂 Exercises Organization
The exercises follow the same structure used by Beecrowd:

- 📁 **Beginner**
Basic programming concepts and logic

- 📁 **Data Structures and Libraries**
Arrays, matrices, stacks, queues, lists, and maps

- 📁 **Mathematics**
Mathematical calculations, number theory, and arithmetic problems

- 📁 **Ad-Hoc**
Miscellaneous problems that require creative solutions

- 📁 **Strings**
String manipulation and text processing

- 📁 **Graphs and Computational Geometry**
Graph algorithms, shortest paths, and geometry problems

- 📁 **Paradigms**
Dynamic programming, divide and conquer, backtracking, etc.
